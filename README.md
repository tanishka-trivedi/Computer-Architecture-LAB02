This project implements a 32-bit Single-Bus Datapath using Verilog HDL as part of a Digital Design / Computer Organization assignment.

The datapath consists of 32-bit registers connected through a common bus, a multiplexer, and an Arithmetic Logic Unit (ALU). The design supports controlled register transfers and arithmetic and logical operations using appropriate control signals.

A Verilog testbench is developed to initialize the registers, execute the specified micro-operations, and verify the functionality of the datapath through simulation.
